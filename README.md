# 🔎 JobLens — Job Market Skills & Salary Analytics
An interactive dashboard for exploring job roles, skills, salaries, and hiring locations using Python, Pandas, and Streamlit.
## ✨ Features

- 📊 Job role analysis
- 💻 Skill demand analysis
- 💰 Salary analysis
- 📍 Job opportunities by location
- 🔎 Interactive job filters
- 📥 Download filtered job data
- 📈 Data visualization
- ## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- Git & GitHub
- ## ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the Streamlit application.

```bash
streamlit run app.py
